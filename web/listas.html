▤ LISTAS DE CARTAS

—
Cada lista é o pool permitido de uma fase — a Lista 1 é a que o jogador e os NPCs usam hoje. Ela tem duas partes: os tipos por regra (todo monstro Normal, toda Fusão vanilla… marcados nas caixinhas de cada lista) e as cartas avulsas, escolhidas uma a uma no pool à direita — é aqui que entra magia, armadilha, Sincro, Xyz. Clique numa lista pra selecioná-la e depois nas cartas do pool; o pool tem os mesmos filtros do Deck Builder (nome, tipo, atributo, raça, arquétipo, tag, raridade, nível, ATK/DEF, banlist) mais um de pertinência, pra ver só o que já está na lista — ou só o que ainda falta. Salvar publica no Supabase (fonte + resultado resolvido) — é o mesmo array que o servidor confere ao salvar um deck, então não precisa rodar mais nada nem publicar Release. Só admin publica.
